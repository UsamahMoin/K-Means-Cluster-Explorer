What the datasets reveal

Geometric groups are not always human categories.

A class label describes a task. A cluster describes distance structure. Agreement can be strong, partial, or weak without making either description invalid.

From-scratch method

Careful seeds, repeated search, honest diagnostics.

The implementation preserves the assignment's core algorithm while using the standard squared-distance objective and multiple initializations to reduce sensitivity to unlucky seeds.

01

Seed

Choose the first centroid randomly, then sample later centers in proportion to squared distance from existing centers.

02

Assign

Place each object in the cluster whose centroid has the smallest squared Euclidean distance.

03

Update

Replace each centroid with the mean of its members and repeat until center movement stops.

04

Restart

Run six deterministic initializations for every k and retain the partition with the lowest inertia.

05

Validate

Measure silhouette without labels, then use adjusted Rand only as an external comparison with known classes.

06

Project

Fit PCA only for the browser scatterplot. The clustering itself remains in the original feature space.
